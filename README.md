# 📊 Market Price Dashboard - Real-time Visual Insight via MetaTrader5 & Streamlit

Dashboard interaktif ini menampilkan data harga dari berbagai aset (XAUUSD, EURUSD, saham, dll) menggunakan **MetaTrader5**, dengan visualisasi **candlestick chart**, **moving average (MA10 & MA21)**, serta **indikator RSI** lengkap dengan insight otomatis seperti **Golden Cross / Death Cross detection**.

---

## 🚀 Fitur Utama

- ⏱️ Real-time data via MetaTrader5
- 📈 Candlestick chart + Moving Averages
- 🟢🔴 Deteksi otomatis Golden & Death Cross
- 📊 RSI indikator + insight analitik otomatis
- 🎛️ Filter rentang tanggal, timeframe, dan simbol
- 💬 Insight pasar secara otomatis berbasis analisis teknikal
